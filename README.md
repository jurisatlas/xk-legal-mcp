## Serveri Ligjor MCP (`xk-legal-mcp`) — Shqip

### Rreth këtij depoje (Repository)

Ky depo përmban serverin Model Context Protocol (MCP) që lidh aplikacionin tuaj të inteligjencës artificiale (Claude Desktop, Cursor, Windsurf, VS Code / Copilot, Cline ose Antigravity) me fletoret zyrtare dhe bazat e të dhënave të vendimeve gjyqësore për **Kosovo** (gjykatat e shkallës së parë / themelore, gjykatat e apelit dhe gjykatat e larta / supreme e kushtetuese).

### Instalimi i shpejtë (Zgjedhja e aplikacionit AI)

1. **Shkarkimi:** Klikoni **`<> Code` -> `Download ZIP`** dhe nxirrni dosjen në kompjuterin tuaj.
2. **Nisja e instaluesit:** Klikoni dy herë mbi **`Click_Here_To_Install_Windows.bat`** (Windows) ose **`Click_Here_To_Install_Mac.command`** (macOS).
3. **Zgjedhja e AI:** Zgjidhni programet AI që përdorni (Claude, Cursor, Windsurf, VS Code, Antigravity), klikoni butonin e instalimit dhe rinisni aplikacionin tuaj AI.

**Shënim sigurie:** Ky mjet funksionon vetëm në mënyrë leximi (read-only) dhe nuk prek ose ndryshon asnjë skedar personal në kompjuterin tuaj.

## English Documentation

Model Context Protocol (MCP) server providing live, read-only access to **Kosovo (XK)** legislation, official gazettes, multi-tier judicial decisions (First Instance, Regional/Cantonal/Appellate, and Supreme/Constitutional courts, including HTML and PDF full-text extraction), and statutory citation verification across all major AI clients (**ChatGPT Desktop, OpenAI Codex CLI, Claude Desktop, Claude Code CLI, Cursor, Windsurf, VS Code / GitHub Copilot / Cline / Roo Code, Google Antigravity / Gemini CLI, Perplexity, and Continue.dev**).

---

### Interactive Desktop Setup (Select Your AI Assistant)

This package includes a graphical installer for legal practitioners and non-technical users that lets you select which AI application(s) you use:

1. **Download:** Click **`<> Code`** at the top right of this repository, select **`Download ZIP`**, and extract the folder to your computer.
2. **Run the Setup Utility:**
   - **Windows:** Double-click `Click_Here_To_Install_Windows.bat`
   - **macOS:** Double-click `Click_Here_To_Install_Mac.command`
3. **Select Your AI Client(s) & Connect:** Check the box(es) for the AI assistant(s) installed on your computer (**ChatGPT Desktop & OpenAI Codex CLI**, **Claude Desktop & Claude Code CLI**, **Cursor**, **Windsurf**, **VS Code / GitHub Copilot / Cline / Roo Code**, **Google Antigravity / Gemini CLI**, or **Perplexity / Continue.dev**), click **Install to Selected AI Clients**, and restart your selected AI application.

**System Integrity Note:** The setup utility operates strictly in read-only mode with respect to your personal files and documents. It installs an isolated Python runtime inside the extracted folder and registers the server entry only in the AI client configuration files you select.

---

### Multi-Tier Judicial Hierarchy & Live Indexed National Archives

This server performs live queries across the full judicial hierarchy and official legal archives of **Kosovo**, extracting full text from both HTML pages and official court/gazette PDF judgments:

| Judicial Tier | Covered Courts & Tribunals |
|:---|:---|
| **Tier 1 — First Instance** | 7 Gjykatat Themelore (Basic Courts: Prishtinë, Prizren, Pejë, Gjilan, Gjakovë, Mitrovicë, Ferizaj) & Gjykata Komerciale (First Instance Chambers) |
| **Tier 2 — Regional / Cantonal / Appellate** | Gjykata e Apelit e Kosovës (Court of Appeals in Prishtinë) & Gjykata Komerciale (Second Instance Chambers) |
| **Tier 3 — Supreme & Constitutional** | Gjykata Supreme e Kosovës (supreme.gjyqesori-rks.org) & Gjykata Kushtetuese (gjk-ks.org) |

#### Official Portals & Live Indexed Domains

- **National Legislation & Official Gazette:** Gazeta Zyrtare e Republikës së Kosovës (gzk.rks-gov.net Official Gazette) — [https://gzk.rks-gov.net](https://gzk.rks-gov.net)
  - *Indexed Legislation Domains:* `gzk.rks-gov.net`, `kuvendikosoves.org`, `rks-gov.net`
- **Court Decisions & Jurisprudence Archives:** Këshilli Gjyqësor i Kosovës - Regjistri i Vendimeve Gjyqësore (gjyqesori-rks.org) — [https://www.gjyqesori-rks.org/aktgjykimet/](https://www.gjyqesori-rks.org/aktgjykimet/)
  - *Indexed Judicial & Open Case Law Domains:* `gjk-ks.org`, `gjyqesori-rks.org`, `rks-gov.net`

### Available MCP Tools

| Tool | Description |
|:---|:---|
| `search_legislation` | Searches enacted statutes, codes, decrees, and official gazette publications in Kosovo. |
| `search_case_law` | Searches national jurisprudence and open judicial archives for Kosovo. |
| `search_tiered_court_decisions` | Filters case law specifically by judicial instance (`first_instance`, `appellate_regional`, `supreme_constitutional`) or specific regional/cantonal/district court. |
| `list_court_hierarchy` | Returns the complete 3-tier court structure and supported regional court filters for Kosovo. |
| `get_legal_document_markdown` | Retrieves full statutory or judicial texts (both HTML and official `.pdf` court judgments) and converts them into clean Markdown. |
| `verify_citation` | Validates statutory and case law citations against official registries. |
